# Native reviewer instructions
Listen to each clip once or twice, read the lyrics, fill `reviewer-sheet.csv` (1 = poor, 5 = natural for a native singer): stress/meter, word boundaries, vowel length, melody fit, overall singability; give the worst line number and a note. Do not look up scores. Say which language(s) you are a native speaker of.
Regenerate the packet: `python3 scripts/quality/make-reviewer-packet.py <audio_dir> <out_dir>`.
