# UI localization

Languages: English (source), हिन्दी, தமிழ், తెలుగు, ಕನ್ನಡ, বাংলা.

- Strings live in `apps/web/lib/i18n/locales/<lang>.ts`; `en.ts` defines the keys.
- Language is chosen server-side: cookie `neo-fm-lang` first, then `Accept-Language`, then English. The switcher in the nav and user menu writes the cookie and refreshes.
- Server components use `serverI18n()`; client components use `useUiLang()`; JSX text can use `<T k="..." />`.
- `{name}` placeholders and the `[[accent]]` marker must match English in every locale.
- `tests/lib/i18n-coverage.test.ts` fails CI when a locale misses a key, a key used in code is undefined, a key is unused, or placeholders drift.

## Review status

All non-English locales are first-pass translations marked `pending-review` in `TRANSLATION_STATUS` (`lib/i18n/ui-strings.ts`); the switcher flags them. After a native speaker signs off, flip that locale to `reviewed`.

Terms and Privacy show a localized plain-language summary above the governing English text.

## Intentionally left in English

- Edge-rendered images (Open Graph, share card, dedication image) and `/admin/health`.
- Style-preset titles/descriptions and raga, tala and instrument names (data from `@neo-fm/style-presets` and the song document).
- Raw server or API error text, and user-generated content.
- Email templates (rendered outside the web app).
